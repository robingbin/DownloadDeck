# Third-party software

The Windows package of DownloadDeck bundles these programs and libraries. Each stays under its own license.

| Component | Used for | License |
|---|---|---|
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) + yt-dlp-ejs | Reading video sites | [Unlicense](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE) |
| [FFmpeg](https://ffmpeg.org) (build from [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)) | Merging video + audio, MP3/M4A conversion | [GPL / LGPL](https://ffmpeg.org/legal.html) - source at ffmpeg.org |
| [Deno](https://deno.com) | JavaScript runtime yt-dlp uses for YouTube | [MIT](https://github.com/denoland/deno/blob/main/LICENSE.md) |
| [Qt for Python (PySide6)](https://doc.qt.io/qtforpython/) | User interface | [LGPL v3](https://www.gnu.org/licenses/lgpl-3.0.html) - dynamically linked, replaceable DLLs in `_internal` |
| [Requests](https://requests.readthedocs.io) | HTTP downloads | [Apache 2.0](https://github.com/psf/requests/blob/main/LICENSE) |
| [Python](https://www.python.org) | Runtime | [PSF License](https://docs.python.org/3/license.html) |
| [PyInstaller](https://pyinstaller.org) | Packaging | [GPL with bootloader exception](https://github.com/pyinstaller/pyinstaller/blob/develop/COPYING.txt) |
